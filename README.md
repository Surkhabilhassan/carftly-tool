# Tidy Text Toolkit

Build a premium, classic website called Craftly Tools using Astro, JavaScript, and custom CSS. Include a homepage with a hero section, search bar, popular tools, and category cards. Add All Tools, individual pages for Word Counter, Text Case Converter, URL Slug Generator, and Meta Tag Preview, plus Guides, About, Contact, Privacy Policy, and Terms pages. Use a minimal black, off-white, and gold design with responsive layouts, working tools, smooth animations, SEO-friendly URLs, and a clean footer. Keep the code lightweight, reusable, and suitable for free Netlify static hosting. Prepare optional AdSense placements for future monetization. Make every button functional and avoid fake content.
